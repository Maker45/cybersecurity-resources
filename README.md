## Free Practice VM Images (VMware)

**CyberPatriot-style hardening images**

- [Aperture Science Practice Image Bundle (GitHub)](https://github.com/anishgoyal1108/Aperture-Science-Practice-Image-Bundle) *(Ubuntu + Windows, 100 vulns each; built for VMware Workstation 17+)*
- [Ethan Ho's CyberPatriot Practice Images](https://eth007.me/blog/projects/) *(System Hardening series; Ubuntu 22 and Windows)*

**Attack-style vulnerable VMs (pentest / CTF practice)**

- [VulnHub](https://vulnhub.com/) *(some VMs are VirtualBox-only; check each listing)*
- [VPLE – Vulnerable Pentesting Lab Environment](https://sourceforge.net/projects/pvple/) *(DVWA, Mutillidae, WebGoat, bWAPP, Juice Shop; VMware only)*

> These are community-made, unvetted images. Run them on a host-only or NAT network and take a snapshot first.
